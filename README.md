# Nexus — النسخة المحسنة

هذه نسخة React منظمة مستوحاة من لعبة Nexus الموجودة في مستودع `FY881/Game`. تحافظ النسخة على فكرة المختبر الذهني، وتضيف مركزًا واضحًا للتقدم، اختبارًا سريعًا من خمس عقد، أثرًا تعليميًا بعد الإجابة، وخريطة مغامرة مترابطة. المصدر الأصلي الكبير ذو الملف الواحد جرى فحصه وتوثيق أولوياته، بينما يبدأ هذا المسار من واجهة جديدة قابلة للتوسع بدل نسخ الملف كله إلى مكوّن واحد.

## التشغيل

```bash
pnpm install
pnpm dev
```

للتحقق من الجودة استخدم `pnpm check` ثم `pnpm build`. لا تحتاج النسخة الحالية إلى خادم خلفي أو مفاتيح API؛ التقدم يحفظ في `localStorage` تحت مفتاح بإصدار واضح.

## المسارات

| المسار | الغرض |
|---|---|
| `/` | مركز اللعب، ملخص التقدم، المهام، وأوضاع Nexus. |
| `/play` | حلقة الاختبار السريع مع المؤقت، السلسلة، والتفسير. |
| `/adventure` | أطلس المحطات الخمس وحالات الفتح والقفل. |

## الخطوة التالية

ينبغي ترحيل أوضاع المغامرة والزنزانة والصالة من المصدر الأصلي إلى وحدات مستقلة واحدة تلو الأخرى بعد اعتماد حلقة الأسئلة الجديدة. لا ينبغي نقل مفاتيح Firebase أو رموز لوحة المالك إلى الواجهة؛ الأونلاين الحقيقي يحتاج خدمة خلفية وصلاحيات آمنة.

# ممالك النرد — مشروع Android

هذه ليست واجهة ويب. هذا مستودع مصدر **Flutter + Flame** للعبة Android عربية أصلية بقواعد سباق أحجار مألوفة. لا يتضمن المشروع أي علامة، رسومات، صوتيات، أو نصوص من لعبة طرف ثالث.

## ما تم إنشاؤه في هذه البداية

يتضمن المشروع نواة قواعد كلاسيكية مستقلة عن الرسم، لوحة Flame مرسومة برمجيًا، شاشة Android عربية RTL، رمية نرد، حركة أحجار قانونية، التقاط خارج الخانات الآمنة، دخول المسار النهائي، وفوزًا عند إكمال الأحجار الأربعة. كما يتضمن اختبارات Dart للنواة.

## المتطلبات المحلية

يحتاج هذا المستودع إلى Flutter SDK وAndroid SDK، وهما غير مثبتين في بيئة العمل الحالية. بعد توفير Flutter، نفّذ الأوامر التالية من جذر المستودع:

```bash
flutter create .
flutter pub get
flutter test
flutter run
```

لإنشاء حزمة اختبار Android لاحقًا:

```bash
flutter build apk --debug
```

وللنشر، استخدم توقيعًا خاصًا بك ثم أنشئ `AAB` عبر `flutter build appbundle --release`.

## حدود البداية

الأونلاين والحسابات والشراء والتصنيف والخوادم ليست منفذة بعد. لا تُدّعى الجاهزية لـ Google Play قبل إعداد Android SDK والتوقيع، واختبار جهاز حقيقي، وسياسة الخصوصية، والتحقق الخادمي.

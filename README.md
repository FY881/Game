# Nexus — النسخة المحسنة

هذه نسخة React كاملة مستوحاة من لعبة Nexus الموجودة في مستودع `FY881/Game`. تضم مركز التقدم، اختبارًا تكيفيًا من خمس عقد، أثرًا تعليميًا بعد الإجابة، ممالك مغامرة وحراسًا، ملف لاعب ورفيقًا، مجتمعًا حيًا محميًا بالحساب، آركيدًا، اقتصادًا داخليًا، لوحة مالك، ومراقب Nexus Architect المحدود. المصدر الأصلي الكبير ذو الملف الواحد جرى فحصه وتوثيق أولوياته، بينما يبدأ هذا المسار من واجهة جديدة قابلة للتوسع بدل نسخ الملف كله إلى مكوّن واحد.

## التشغيل

```bash
pnpm install
pnpm dev
```

للتحقق من الجودة استخدم `pnpm check` ثم `pnpm test` ثم `pnpm build`. يدعم المشروع مصادقة Manus، قاعدة بيانات MySQL/TiDB، مزامنة تقدم اختيارية، وSocket.IO للغرف الحية تحت الاستضافة الدائمة.

## المسارات

| المسار | الغرض |
|---|---|
| `/` | مركز اللعب، ملخص التقدم، المهام، وأوضاع Nexus. |
| `/play` | حلقة الاختبار السريع مع المؤقت، السلسلة، والتفسير. |
| `/adventure` | أطلس المحطات الخمس وحالات الفتح والقفل. |
| `/profile` | ملف اللاعب والرفيق والشارات والمقاييس الفعلية. |
| `/community` | غرف حية، دردشة، بطولة أسبوعية، وعصابات. |
| `/arcade` | ثلاث تجارب آركيد ولوحات نتائج فعلية. |
| `/shop` | محفظة داخلية ومشتريات بالذهب المكتسب. |
| `/owner` | لوحة مالك محمية لإدارة الصيانة وسجل التدقيق. |
| `/architect` | مراقب صحة دوري محمي بتوصيات آمنة فقط. |

## Nexus Architect

يسجل **Nexus Architect** صحة المنصة وتوصيات قابلة للمراجعة فقط. لا ينشر كودًا، ولا يحذف أو يغير البيانات الحساسة، ولا ينقل أرصدة أو يغير الأدوار. راجع [سياسة Nexus Architect](./NEXUS_ARCHITECT_POLICY.md) لمعرفة الصلاحيات وخطوات التحقق بعد إضافة أول حساب مالك.

## الخطوة التالية

بعد إضافة أول حساب، اختبر تسجيل الدخول والمزامنة السحابية والغرف والدردشة والعصابات والبطولة والآركيد والمتجر ولوحة المالك. لا ينبغي نقل مفاتيح Firebase أو رموز الإدارة إلى الواجهة؛ كل الأونلاين في هذه النسخة يمر عبر خدمة خلفية وصلاحيات آمنة.

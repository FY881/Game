# معمارية ممالك النرد — Android

> **المبدأ:** محرك القواعد لا يعرف Flutter أو Flame. تستطيع واجهة Android أو خادم المباراة استعمال القواعد نفسها دون نسخ المنطق.

| الطبقة | المسؤولية | الحالة |
|---|---|---|
| `core/models` | نماذج اللاعب والحجر وحالة المباراة | منفذة |
| `core/rules` | الحركة القانونية، الالتقاط، المسار النهائي، الفوز | منفذة محليًا |
| `core/game` | لوحة Flame المرئية | منفذة كبداية |
| `features/offline_game` | التحكم بحالة المباراة وواجهة اللعب | منفذة كبداية |
| `features/online_game` | طلب رمية من الخادم وتلقي الحالة الموثوقة | مؤجل |
| `server` | نرد آمن وتحقيق حركة وغرف ومطابقة واقتصاد | مؤجل |

لن يُنقل مولد النرد المحلي إلى الأونلاين؛ في المباراة المتصلة يطلب العميل الرمية فقط ويتحقق الخادم من النتيجة والحركة.

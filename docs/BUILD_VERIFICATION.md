# تحقق البناء الأولي

تمت تهيئة مشروع Flutter Android محليًا وإنشاء مجلد `android/` الرسمي. اجتازت حزمة الاختبارات الحالية خمسة اختبارات، تشمل الشاشة الافتتاحية وأربع حالات لقواعد اللعب. كما أنتج البناء المحلي حزمة APK اختبارية في المسار التالي:

```text
build/app/outputs/flutter-apk/app-debug.apk
```

هذه الحزمة **Debug** فقط وليست جاهزة للنشر ولا موقعة بمفتاح إصدار. ما زال يلزم اختبارها على هاتف Android فعلي، وإضافة الأيقونات والأصول الأصلية، وتحضير توقيع إصدار وملف AAB عند الوصول لمرحلة الإطلاق.

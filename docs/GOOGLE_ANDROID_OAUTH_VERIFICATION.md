# سجل تحقق Android OAuth — بيئة Debug

**تاريخ التحقق:** 14 أغسطس 2026  
**النطاق:** بناء Debug لتطبيق «ممالك النرد: صراع الأبطال» فقط.

| بند التدقيق | القيمة أو النتيجة |
|---|---|
| اسم الحزمة المحلي | `com.example.mamalik_alnard` |
| مصدر اسم الحزمة | `android/app/build.gradle.kts` عبر `applicationId` |
| بصمة SHA‑1 المحلية | `7F:5C:D9:C9:93:26:3F:A9:BC:04:FA:A8:5D:87:28:C7:4E:D0:FD:CE` |
| مصدر البصمة | شهادة Debug المحلية باستخدام `keytool` |
| عميل Google Cloud | عميل Android Debug المسمى **Mamalik AI-Nard Android Debug** |
| مطابقة Google Cloud | لقطتا الشاشة اللتان قدمهما مالك المشروع في هذه المحادثة تعرضان اسم الحزمة والبصمة نفسيهما في صفحة عميل Android |
| الحالة | **مطابق لبناء Debug** |

> لا يحتوي هذا السجل على Client Secret أو مفاتيح توقيع. معرّف عميل Web يبقى في بيئة الخادم ويمرر فقط كإعداد بناء مؤقت عند اختبار Google Sign-In.

## حدّ التحقق

يثبت هذا السجل إعداد OAuth لبناء Debug، ولا يثبت نجاح مصادقة Google على جهاز فعلي. قبل فتح الأونلاين العام يجب تثبيت APK الاختباري على هاتف أو محاكي يدعم Google Play services، ثم ربط حساب تجريبي والتأكد من استجابة الخادم. ويتطلب إصدار Google Play بصمة توقيع Play App Signing وعميل Android منفصلًا أو بصمة إضافية.

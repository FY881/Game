# معمارية الخادم الموثوق للأونلاين

## مبدأ الثقة

الهاتف واجهة إدخال وعرض فقط. يرسل اللاعب طلب رمية أو حركة، ويحتفظ الخادم بحالة الغرفة والمباراة وسجل الأحداث. لا يقبل الخادم رقم نرد أو موضع حجر أو فائزًا يرسله العميل.

## مراحل الإصدار الأول

| الطبقة | مسؤوليتها في الإصدار الأول | ما يؤجل قبل الإنتاج |
|---|---|---|
| الهوية | حساب ضيف، جلسة وصول، تحديث جلسة، وترقية Google متحققة | ربط حسابات متعددة وحذف/تصدير البيانات |
| اللعبة | قواعد كلاسيكية للاعبين اثنين، رمية خادمية، حركة خادمية، التقاط وفوز | وضع الأبطال والفرق والبطولات |
| الغرف | إنشاء غرفة خاصة والانضمام برمز وإعادة مزامنة الحالة | مطابقة عامة وRedis ومناطق خادم متعددة |
| النقل | REST للهوية وWebSocket للأحداث الفورية | طوابير موزعة وإعادة تشغيل خادمية متقدمة |
| التخزين | ذاكرة مؤقتة لاختبار العقود | PostgreSQL وRedis وسجل أحداث دائم قبل الإنتاج |

## حدود الإطلاق

لا يُفعّل زر اللعب الأونلاين في Flutter افتراضيًا حتى يُنشر الخادم الدائم، وتُضاف قاعدة بيانات وتُضبط أسرار Google وJWT. لا يتضمن هذا الإصدار إعلانات أو مشتريات أو اقتصادًا متصلًا، ولا توجد دردشة نصية حرة.

## عقد التفعيل

يدعم الخادم REST لمسارات إنشاء الضيف وتحديث الجلسة وربط Google، وWebSocket لمسارات الغرفة والرمية والحركة والمزامنة. اختبار النقل يثبت أن جلسة ضيف مصدقة يمكنها إنشاء غرفة خاصة وأن الخادم يرفض رمية لاعب خارج دوره.

لتفعيل العميل في بيئة اختبار فقط يمرر البناء القيمتين التاليتين، ولا تُضافان إلى أي ملف مصدر:

```bash
flutter run \
  --dart-define=MAMALIK_ONLINE_ENABLED=true \
  --dart-define=MAMALIK_SERVER_URL=https://your-server.example
```

وتبقى Google معطلة ما لم يضبط الخادم `GOOGLE_ANDROID_CLIENT_ID` بمعرف عميل Android المسجل في Google Cloud. لا يقبل الخادم رمزًا من العميل دون التحقق من التوقيع والجمهور وصلاحية البريد من Google.

## قبل النشر العام

يجب نقل التخزين من الذاكرة إلى PostgreSQL وRedis، وضبط سر JWT عشوائيًا بطول 32 بايت أو أكثر ضمن مدير أسرار، وإضافة سجل أحداث دائم وحدود معدل الطلبات ومراقبة الأعطال. يحتاج WebSocket إلى عملية دائمة واحدة؛ لا يُفعّل هذا النمط المدفوع قبل موافقة مالك المشروع على تكلفة الاستضافة المتغيرة.

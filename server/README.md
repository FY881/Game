# خادم ممالك النرد الموثوق

هذه الحزمة هي خادم TypeScript مستقل للمباريات الأونلاين. **لا يثق الخادم بأي نرد أو حركة أو فوز صادر من الهاتف.** يستقبل فقط نية اللاعب، ثم يولد النرد ويتحقق من الدور والحركة والالتقاط والفوز قبل بث الحالة المعتمدة عبر WebSocket.

## نطاق الإصدار الأول

يدعم الخادم حسابات ضيف وجلسات قصيرة العمر ورموز تحديث قابلة للإلغاء، وترقية حساب الضيف برمز Google ID Token بعد ضبط `GOOGLE_ANDROID_CLIENT_ID`، وغرفًا خاصة ومباراة كلاسيكية للاعبين اثنين. التخزين الحالي داخل الذاكرة بهدف اختبار العقود؛ قبل تشغيل إنتاجي يجب استبداله بـ PostgreSQL وRedis مع سجل أحداث دائم وتشفير أسرار الإنتاج.

## أوامر التطوير

```bash
cd server
pnpm install
cp .env.example .env
pnpm test
pnpm check
pnpm dev
```

## أحداث WebSocket

| الاتجاه | الحدث | المعنى |
|---|---|---|
| عميل → خادم | `room:create` | إنشاء غرفة خاصة بعد التحقق من الجلسة. |
| عميل → خادم | `room:join` | الانضمام برمز الغرفة. |
| عميل → خادم | `room:start` | يبدأه المضيف بعد اكتمال اللاعبين. |
| عميل → خادم | `match:roll` | طلب رمية؛ يولد الخادم القيمة. |
| عميل → خادم | `match:move` | طلب تحريك حجر؛ يتحقق الخادم من قانونيتها. |
| خادم → عميل | `room:state` | حالة الغرفة المعتمدة. |
| خادم → عميل | `match:state` | حالة المباراة وسجل الحدث المعتمد. |
| خادم → عميل | `server:error` | خطأ آمن برمز قابل للعرض. |

## Google والاستضافة الدائمة

لن تقبل ترقية Google ما لم يُضبط معرف عميل Android الحقيقي في بيئة الخادم. لا يُحفظ أي سر في تطبيق Flutter أو هذا المستودع. تشغيل WebSocket بصورة دائمة يتطلب عملية خادم واحدة مستمرة؛ في الاستضافة المُدارة المخصصة لذلك توجد تكلفة استخدام حتى **37.50 دولارًا شهريًا** عند استهلاك الحد الأقصى طوال الشهر، قبل رصيد الاستخدام الشهري البالغ 10 دولارات، إضافة إلى النقل. لا تُفعّل الاستضافة أو Google قبل إدخال الأسرار وموافقة مالك المشروع.
